# Karoo Audit System

This repository contains the database schema, data, and automation scripts for the Karoo Audit project.

## Files
- `test_data.sql`: SQL script to initialize tables and sample data.
- `auditor_views.sql`: SQL script defining the health monitoring views.
- `audit_suppliers.py`: Python automation script to flag high-risk suppliers.
- `karoo_audit.db`: The SQLite database file.
